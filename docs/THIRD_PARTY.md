# Third-party material

## Atkinson Hyperlegible

The «Easy to read» note font is **Atkinson Hyperlegible** (Regular and Bold), © 2020 Braille Institute of America, Inc., under the
[SIL Open Font License 1.1](../src/Aldune/Assets/AtkinsonHyperlegible-OFL.txt). It is bundled unmodified as an embedded resource of the
Windows app (`src/Aldune/Assets/`). It is the only font Aldune redistributes: the other choices use fonts already on the device, and an
imported or installed font stays on the device it was chosen on.
