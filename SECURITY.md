# Security

If you find a vulnerability, **do not open a public issue**. Use “Report a vulnerability” in the
[Security](https://github.com/NachoPola16/aldune/security) tab of the repository: it reaches only the maintainer.

Include the version (Windows or Android), the steps to reproduce it and what impact you think it has. I will reply within a few days.
Do not paste profile codes, tokens or the content of your notes, not even in a private report.

The security model of sync (what the server sees, what is encrypted, what is not) is in [docs/SYNC.md](docs/SYNC.md),
section “Modelo de seguridad” (the docs are in Spanish for now), and the one for password-protected notes is in [docs/PROTECTED_NOTES.md](docs/PROTECTED_NOTES.md).
